# 软件需求质量审查系统

一个基于「规则引擎 + 大模型语义分析」的软件需求质量审查平台。

## 项目简介

针对软件需求文档中普遍存在的歧义、冲突、重复、不可验证等质量问题，本系统利用大模型（DeepSeek）的语义理解能力与向量检索技术，自动识别需求问题、定位问题位置、给出依据与建议，识别信息缺口并生成澄清问题，最终建立「需求—测试用例」追踪矩阵，实现需求质量的可量化管理与闭环改进。

## 核心功能

1. 需求录入与版本维护（文档导入、条目编号、版本管理）
2. 检查规则管理（歧义 / 冲突 / 重复 / 不可验证）
3. AI 智能审查（检索上下文、输出问题位置 / 依据 / 建议）
4. 信息缺口识别与澄清问题
5. 用户确认修改
6. 测试用例生成与关联需求编号
7. 追踪矩阵与未覆盖需求标识
8. 缺陷验收与报告导出

## 角色

- 需求编写人员

## 技术栈

- 后端：Python / FastAPI / SQLAlchemy
- 前端：Vue 3 / TypeScript / Element Plus
- 数据库：MySQL / 向量数据库
- AI：DeepSeek API（RAG 检索增强）
- 部署：Docker Compose
